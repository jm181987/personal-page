# Sitio web personal

Proyecto de sitio personal con recursos visuales y una vista de presentación.

## Tecnologías

Sitio web.

## Cómo empezar

Clona el repositorio y revisa el archivo de entrada y los recursos de la carpeta `assets/`.

Repositorio: https://github.com/jm181987/personal-page

## Mantenimiento y seguridad

- Comprueba los requisitos y scripts disponibles antes de desplegar.
- No publiques claves, tokens, contraseñas ni archivos de entorno.
- Documenta los cambios y los problemas reproducibles mediante issues o pull requests.
